# Atlas example board

`atlas/` contains the same six Gerber/Excellon sources as the built-in demo.
Open the folder to test the full import pipeline:

```sh
./target/release/gerbrr examples/atlas
./target/release/gerbrr inspect examples/atlas
```

This is illustrative artwork, **not a validated electrical design or a board to
manufacture**. It has no netlist, DRC, or manufacturing sign-off.

The files are generated by `document::demo_sources` and MIT licensed along with
the application. To export a fresh set without replacing existing files:

```sh
./target/release/gerbrr demo-export path/to/new-folder
```
